# PROMPT PARA CRIAR LANDING PAGE - TIAGO COELHO PERSONAL TRAINER

---

## 📝 INSTRUÇÕES PARA A IA:

Crie uma landing page moderna, responsiva e de alta conversão para consultoria online de personal trainer. Use React/Next.js ou HTML/CSS/JS puro, com Tailwind CSS para estilização.

---

## 🎨 DESIGN SYSTEM

### Paleta de Cores:
- Primary (Azul): `#1E3A8A`
- Accent (Laranja): `#F97316`
- Success (Verde): `#10B981`
- Background: `#FFFFFF`
- Gray Light: `#F3F4F6`
- Gray Dark: `#1F2937`

### Tipografia:
- Headlines: `font-family: 'Montserrat', sans-serif; font-weight: 700`
- Body: `font-family: 'Inter', sans-serif; font-weight: 400`
- Font sizes: Mobile 14-16px body, 32-40px headlines / Desktop 16-18px body, 48-64px headlines

### Componentes Visuais:
- Border-radius: 12px para cards
- Box-shadow: `0 4px 6px -1px rgba(0, 0, 0, 0.1)`
- Hover effects: elevação e mudança de cor
- Transições: 0.3s ease-in-out

## 🎯 REQUISITOS TÉCNICOS

### Responsividade:
- Mobile-first approach
- Breakpoints: 640px (sm), 768px (md), 1024px (lg), 1280px (xl)
- Todas as seções devem funcionar perfeitamente em mobile

### Interatividade:
- Scroll suave entre seções ao clicar nos CTAs
- Hover effects em botões (elevação, mudança de cor)
- Accordion funcional no FAQ
- Animações sutis ao entrar na viewport (fade-in, slide-up)

### Performance:
- Lazy loading de imagens
- Otimização de fontes (preload)
- Minificação de CSS/JS
- Tempo de carregamento < 3 segundos

### SEO:
- Meta tags adequadas
- Heading hierarchy correta (H1 único, H2 para seções, H3 para sub-seções)
- Alt text em todas as imagens
- Schema markup para organização e avaliações

### Formulário (se incluir):
- Campos: Nome, Email, WhatsApp, Plano de Interesse
- Validação client-side
- Botão de envio com loading state
- Mensagem de sucesso/erro
